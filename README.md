# Учебный frontend-проект

## Описание
Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема проекта: многостраничный сайт интернет-магазина бытовой техники.

## Основа проекта
Контрольная работа №4 выполняется в этом же репозитории `kr1-html-css-shop`.
В качестве основы использован собственный магазин из КР №1 (ПР №1–8). Поверх него добавлены адаптивная вёрстка и доступность (ПР №12–14) и первые JavaScript-файлы (ПР №15). Отдельный репозиторий `kr4-js-shop` не создавался.

## Контрольная работа №1 (ПР №1–8)
Тема: «Многостраничный HTML/CSS-сайт интернет-магазина». Цель: создать сайт из пяти связанных страниц (`index.html`, `catalog.html`, `product.html`, `order.html`, `contacts.html`) с семантической разметкой, навигацией, формой, модальным окном, CSS-переменными, Flex/Grid, БЭМ и позиционированием.

Выполнено по практическим занятиям:
- **ПР №2:** HTML-каркас (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`), сброс стилей и `box-sizing: border-box`, hero, преимущества, популярные товары.
- **ПР №3:** кнопки «Заказать», модальное окно `<dialog>` с формой (имя, e-mail, телефон, дата, тема, комментарий, согласие), HTML-валидация, сообщение об успешной отправке (`js/main.js`).
- **ПР №4:** CSS-переменные в `:root`, состояния `:hover`, `:focus-visible`, `:disabled`.
- **ПР №5:** страницы `catalog.html`, `product.html`, `order.html`, `contacts.html`, единая навигация, якорные ссылки (`#advantages`, `#popular`, в том числе `index.html#...` из подвала), хлебные крошки, уникальные `title` и `description`.
- **ПР №6:** меню на Flexbox, сетка товаров на Grid, каталог «фильтры + товары» через `grid-template-areas`.
- **ПР №7:** БЭМ: `site-nav`, `product-card`, `order-form`, `order-dialog`; без `id`-селекторов и inline-стилей.
- **ПР №8:** позиционирование: `relative` (карточка), `absolute` (бейджи «Хит», «Скидка», «Новинка»), `sticky` (шапка, фильтры), `fixed` (кнопка «Наверх»), `z-index`; таблица характеристик на `product.html`.

## Практическая работа №12. Адаптивная вёрстка
- создан `css/responsive.css`, подключён на всех страницах, есть `viewport`;
- подход Mobile First, медиазапросы `min-width` 640 / 768 / 900 / 1024 px;
- адаптированы навигация, hero, сетка карточек, каталог с фильтром, форма и таблица;
- проверены ширины 360, 430, 768, 1024 и 1440 px.

## Практическая работа №13. Доступность
Выполнено:
- проверены изображения и `alt`-описания (смысловые описания у фото товаров и hero);
- ARIA используется только там, где она нужна: `aria-label`, `aria-current`, `aria-labelledby`, `aria-live`, `aria-hidden` у символа «×»;
- добавлены skip-link, видимый фокус, подписи полей формы;
- подготовлен протокол проверки `lighthouse/accessibility-check.md`; скриншот Lighthouse сохраняется в `lighthouse/accessibility-report.png`.

## Практическая работа №14. Проверка адаптивности
- адаптивная вёрстка страниц: отсутствие горизонтального скролла проверено на пяти ширинах;
- responsive images: `srcset` и `sizes` у карточек товаров и страницы товара, `picture` у hero-блока, `width`/`height` и `loading="lazy"`;
- адаптивные формы (1 колонка на телефоне, 2 колонки с 768 px) и таблица характеристик (`.table-wrapper` с прокруткой).

## Практическая работа №15. JavaScript
Выполнено:
- создана папка `js`, файлы `js/data.js` и `js/main.js`, подключены через `defer` на всех страницах;
- создан объект товара `product` (строки, числа, логическое значение);
- использованы арифметические операторы, операторы сравнения и логические операторы;
- функции `formatPrice`, `calculateDiscount`, `calculateFinalPrice`, `getProductStatus`, `createProductSummary`;
- результаты функций выводятся в консоль (`console.log`, `console.table`);
- сообщение и описание товара выводятся на главной странице через `textContent`.

## Принцип безопасного вывода данных
Для вывода пользовательских данных и данных, которые в будущем могут прийти из формы, `localStorage` или API, используется `textContent`, а не `innerHTML`. `innerHTML` воспринимает строку как HTML, поэтому строка вида `<img src=x onerror=alert(1)>` выполнила бы код. `textContent` показывает её как обычный текст.
