# Проверка доступности (A11y)

> Это протокол проверки, а не отчёт Lighthouse. Сам Lighthouse запускается в DevTools Chrome:
> DevTools → Lighthouse → категория Accessibility → Analyze page load.
> Скриншот результата для `index.html`, `catalog.html` и `order.html` нужно сохранить сюда
> как `accessibility-report.png` (см. ПР №13, этап 15).

## Автоматическая проверка (скрипт Playwright, Chromium)

Проверено 5 страниц на ширинах 360, 430, 768, 1024 и 1440 px (25 проверок).

| Проверка | Результат |
|---|---|
| Горизонтальный скролл страницы | не обнаружен |
| Один `h1` на странице | выполнено на всех страницах |
| `alt` у всех изображений | выполнено |
| Все `input`, `select`, `textarea` связаны с `label` | выполнено |
| Контраст текста и фона не ниже 4.5:1 (WCAG AA) | выполнено для всего видимого текста |
| Skip-link появляется при первом нажатии Tab | выполнено |
| Модальное окно открывается кнопкой и закрывается кнопкой «×» | выполнено |

## Что исправлено / предусмотрено

- Добавлена ссылка пропуска `.skip-link` и `id="main"` у `main`.
- Навигация в `nav` с `aria-label`, текущая страница помечена `aria-current="page"`.
- Видимый `:focus-visible` для ссылок, кнопок и полей формы.
- Все изображения имеют осмысленный `alt`; фото товаров описывают товар, а не слова «картинка».
- Каждое поле формы имеет `label for` + `id`; placeholder не заменяет подпись.
- Кнопка закрытия окна и кнопка «Наверх» имеют `aria-label`, символ скрыт через `aria-hidden`.
- ARIA используется только там, где нет подходящего HTML (`aria-label`, `aria-current`, `aria-labelledby`, `aria-live` у блока вывода JS).
- У таблицы есть `caption`, `th scope`, она в контейнере `.table-wrapper`.
- Цвета: основной текст `#1f2937`, второстепенный `#4b5563`, акцент `#0057b8`.
